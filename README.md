# blue-orca

A small starter repository used to try the dsh-superagent prototype.

## What lives here

- `README.md` — this file
- `greet.sh` — a tiny script that prints a greeting
- `.gitignore` — ignores build output and local state

## Try it

```sh
./greet.sh
./greet.sh Ada        # prints "Hello, Ada!"
./greet.sh --version  # prints "blue-orca 0.1.0"
```
